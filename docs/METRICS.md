# Metric Registry

Every metric shown by Claude Receipt is defined here. A metric that isn't in this file must not be shown. Ids are stable: they are keys in the JSON contract (`ARCHITECTURE.md` §4).

## Provenance

| Provenance | Meaning | Rendering |
|---|---|---|
| `exact` | Read directly from a recorded field, or a plain count of discrete recorded events. No interpretation. | As is |
| `derived` | Deterministic computation over exact data with a documented rule (sums after deduplication, unique counts, max/min, extension maps). Reproducible, but depends on the rule being right. | As is |
| `heuristic` | Involves a threshold, pattern matching, classification or interpretation. May be wrong. | Marked `~`, with a legend |

Rules:

- If the inputs for a metric are missing, its value is `null` with an `unavailableReason`. **Never `0`.** Renderers omit null metrics or show `n/a`.
- A metric's provenance is the weakest provenance among its inputs.
- The playful **label** of a lore metric ("biggest rabbit hole") is framing. Provenance describes the **value**. A derived value with a playful label is still derived, but the label must not claim more than the value supports.

## Sources

| Key | Source |
|---|---|
| **T** | Session transcript `~/.claude/projects/<dir>/<sessionId>.jsonl` plus its subagent files `<dir>/<sessionId>/subagents/agent-*.jsonl` |
| **CS** | `cost-state` record inside T (only in completed sessions) |
| **L** | Live session file `~/.claude/sessions/<pid>.json` |
| **G** | `git` in the session `cwd` |
| **P** | Pricing table bundled with Claude Receipt |
| **A** | Claude Receipt archive (aggregates only) |

The `session.*` identity fields (`id`, `project`, `entrypoint`, `title`, `startedAt`, `endedAt`) are carried in `Receipt.session` rather than in a section. `session.duration.*` metrics are in `sections.hard`.

There is no `plan` metric. Plan display was removed from the product (`PRD.md` §4).

Privacy levels: **none** (numbers only), **meta** (names, paths or ids, which are sensitive in exports), **text** (needs prompt or response text; opt-in only).

## Hard stats

### `session.id`: Session id · exact · MVP
- **Source:** T (`sessionId`, which is also the file name).
- **Calculation:** as is; displayed shortened.
- **Limitations:** `/clear` starts a new id. Resume behaviour is unverified (M0).
- **Privacy:** meta. Truncated in exports.

### `session.project`: Project · exact · MVP
- **Source:** T (`cwd` on records). The name is `basename(cwd)`.
- **Limitations:** a session may `cd` elsewhere. The first record's `cwd` is the project, and others are listed in `detail`.
- **Privacy:** meta. Redacted in exports by default.

### `session.title`: Session title · exact · MVP
- **Source:** T (`ai-title`, generated by Claude Code from the conversation).
- **Limitations:** absent in some sessions.
- **Privacy:** meta, but it summarizes conversation content. Shown in the terminal and `--json` only. **Never archived**, and removed by `--redact` and exports. See `PRIVACY.md`.

### `session.startedAt` / `session.endedAt`: Start and end · exact · MVP
- **Source:** T (first and last record `timestamp`, UTC).
- **Limitations:** for a live session, `endedAt` is the latest record so far.
- **Privacy:** none.

### `session.duration.wall`: Duration · derived · MVP
- **Source:** T.
- **Calculation:** `endedAt − startedAt`.
- **Limitations:** a resumed session is one file spanning several runs (M0 §1), so this includes the gaps between runs, possibly days. Always shown next to active time when the two differ significantly. Not comparable to CS `totalDuration` (see `session.duration.open`).
- **Privacy:** none.

### `session.duration.open`: Open time · exact · MVP
- **Source:** CS `totalDuration`.
- **Calculation:** as is. Claude Code sums the running time of every process run of this session (verified cumulative across resumes).
- **Limitations:** `null` for live and killed sessions (no CS). For forks it includes the parent's time, so it's `null` there. For interactive sessions it includes time the window sat open waiting for input.
- **Privacy:** none.

### `session.runs`: Runs · derived · MVP
- **Source:** T (`Session.runs`, see `ARCHITECTURE.md` §3).
- **Calculation:** a `cost-state` closes the current run. A further `cost-state` with no timestamped record since the last one updates the same run: an interactive CLI exit writes two, separated only by `last-prompt` (M0 addendum). Timestamped records after the last `cost-state` form an open run (live or killed).
- **Limitations:** a killed run leaves no CS and is seen only through its trailing records.
- **Privacy:** none.

### `session.duration.active`: Active time · heuristic · MVP
- **Source:** T (all record timestamps).
- **Calculation:** sum of gaps between consecutive records, where each gap is capped at an idle threshold (initially 5 min; tuned with real data in M1).
- **Limitations:** the threshold is arbitrary, and reading or thinking time without any records looks like idle time.
- **Privacy:** none.

### `api.duration`: Claude working time · exact · MVP
- **Source:** CS `totalAPIDuration`. Detail: `totalToolDuration`.
- **Limitations:** only in completed sessions. `null` otherwise.
- **Privacy:** none.

### `models.used`: Models · exact · MVP
- **Source:** CS `modelUsage` keys when present, else T `assistant.message.model` (unique).
- **Limitations:** auxiliary models (a Haiku model in interactive sessions, M0 §6) appear in CS but not in T. `detail.source` records which source was used. Subagent models come from subagent files.
- **Privacy:** none.

### `tokens.input`, `tokens.output`, `tokens.cacheRead`, `tokens.cacheWrite`: Tokens · exact (CS) or derived (T) · MVP
- **Source:** the last CS `modelUsage[*]` for a **completed, non-fork** session (exact; includes subagents and auxiliary calls). Otherwise T `message.usage` from the main file **plus subagent files**, deduplicated by `message.id` with the last line winning, excluding API calls inherited by a fork (derived).
- **Calculation:** per model and total; `detail.byModel`, `detail.source: "cost-state" | "transcript"`.
- **Limitations:**
  - Transcript sums miss auxiliary calls. In interactive sessions CS was higher by one or more full-context main-model calls, plus a Haiku model; headless sessions matched exactly (M0 §6).
  - Killed sessions lose the in-flight response entirely.
  - Never sum usage without deduplication (it inflates totals about 2×).
  - Never use a fork's CS as its own total (it includes the parent's usage).
- **Privacy:** none.

### `tokens.thinking`: Thinking tokens · exact (CS) or derived (T) · future
- **Source:** CS `thinkingTokens`, or T `usage.output_tokens_details.thinking_tokens` (these reconcile exactly, M0 §6).
- **Limitations:** believed to be a subset of output tokens (INFERRED), so it's never added to totals.
- **Privacy:** none.

### `cost.apiEquivalent`: API EQUIVALENT · exact (CS) or derived (P) · MVP
- **Source:** CS `totalCostUSD` (Claude Code's own estimate) for completed, non-fork sessions. Otherwise the session's own tokens × P.
- **Calculation:** with P: per model, `input×in + output×out + cacheRead×cr + cacheWrite×cw` using the table's rates (including cache-write TTL rates if the usage breakdown distinguishes them).
- **Limitations:** this is **not** money spent and never labelled as such. If CS says `hasUnknownModelCost`, or a model is missing from P, the value is `null` (or, with CS and P, the known part with `detail.incomplete = true`, rendered `~`). The table is dated (`generator.pricingTableDate`).
- **Privacy:** none.

### `prompts.count`: Prompts · exact · MVP
- **Source:** T main file `user` records (M0 §7): `promptSource` `typed` or `sdk`, or a `<command-message>` record with `origin.kind: "human"` (a slash command or skill that sends a prompt).
- **Calculation:** count, with `detail.byKind`. Excluded: tool results, `isMeta`, sidechain (subagent) prompts, local slash commands (`<command-name>`/`<local-command-*>`), user `!` shell records, task notifications. Reference: `promptKind()` in `src/source/claude-code/scan.ts`.
- **Limitations:** the `slash` shape has one observed sample. Queued-while-busy prompts are untraced (M0 §7).
- **Privacy:** none (the text is not kept; the character length is kept in memory for lore).

### `toolCalls.count` / `toolCalls.byName`: Tool calls · exact · MVP
- **Source:** T `tool_use` content entries (deduplicated by tool-use id).
- **Limitations:** MCP tool names include server names (`mcp__server__tool`). They're grouped as `MCP` in exports.
- **Privacy:** meta (MCP server names).

### `turns.count`: Turns · exact · MVP
- **Source:** T `system/turn_duration` records.
- **Limitations:** a turn interrupted before completion may not produce a record.
- **Privacy:** none.

## Coding stats

### `files.read` / `files.created` / `files.edited`: Files · derived · MVP
- **Source:** T. `Read` tool file paths; `Write` results `type: create` or `update`; `Edit` (and `MultiEdit`, `NotebookEdit` if present) file paths.
- **Calculation:** unique paths per category. A file created then edited counts once as created and once in edited.
- **Limitations:** files touched through Bash (`sed`, `cat >`, scripts, generators) are invisible. Greps and globs don't count as reads.
- **Privacy:** meta (paths). Only counts leave the analytics module, except `files.mostEdited`.

### `lines.added` / `lines.removed`: Lines · derived · MVP
- **Source:** T. `Edit` `structuredPatch` (`+` and `-` lines), `Write` create (all lines added), `Write` update (`structuredPatch`). Cross-check: CS `totalLinesAdded` / `totalLinesRemoved`.
- **Limitations:** excludes Bash-driven changes and user edits outside Claude. A mismatch with CS becomes a warning. Compare with `git.lines` for a fuller picture.
- **Privacy:** none (patch text is read in memory to count lines, then discarded).

### `files.mostEdited`: Most edited file · derived · MVP
- **Source:** T.
- **Calculation:** the file with the most Edit/Write operations. Ties are broken by lines changed.
- **Privacy:** meta. Exports show the basename or only the extension, depending on redaction level.

### `languages`: Languages · derived · MVP
- **Source:** T (edited or created file paths).
- **Calculation:** a bundled extension → language map, weighted by lines changed.
- **Limitations:** extensionless files and ambiguous extensions (`.h`) are "Other". Reflects Claude's writes, not the repository's composition.
- **Privacy:** none.

### `commands.count` / `commands.topPrograms`: Shell commands · exact (count) / derived (programs) · MVP
- **Source:** T `Bash` / `PowerShell` tool calls.
- **Calculation:** program = the first word of the first meaningful segment, after stripping env assignments, `sudo`/`time`-style prefixes and `cd …&&` (`classifyCommand` in `src/source/claude-code/commands.ts`). Only programs on a fixed allowlist are kept by name; anything else (custom scripts, internal tools) is `other`.
- **Limitations:** pipelines and scripts are simplified; commands that are only custom scripts all count as `other`.
- **Privacy:** the raw command is **never** stored. Only the allowlisted program name and category are kept.

### `tests.runs`: Test runs · heuristic · MVP
- **Source:** T (command classification).
- **Calculation:** commands matching a bundled pattern list (`pytest`, `vitest`, `jest`, `npm|pnpm|yarn|bun test`, `go test`, `cargo test`, `node --test`, `dotnet test`, `mvn test`, `gradle test`, `rspec`, …).
- **Limitations:** misses custom scripts (`make check`) and may count non-test commands matching a pattern.
- **Privacy:** none.

### `tests.outcome`: Test pass/fail · heuristic · future
- **Source:** T (tool error flag, plus output parsing of known runners).
- **Limitations:** output parsing is fragile. Only shipped for runners with fixture-tested parsers.
- **Privacy:** reads command output in memory, and nothing is stored.

### `errors.toolErrors`: Tool errors · exact · MVP
- **Source:** T `tool_result.is_error === true`.
- **Limitations:** includes permission denials and user rejections, which are not "bugs". Split into categories later (heuristic).
- **Privacy:** none.

### `interruptions`: Interruptions · exact · MVP
- **Source:** T `toolUseResult.interrupted === true` on Bash results (field observed in M0).
- **Limitations:** user interruptions of a response (Esc) have **no verified on-disk shape** (M0 §7: UNKNOWN), so they aren't counted until a real sample is captured. Until then the metric covers interrupted tool runs only, and `detail.scope = "tool-runs"`.
- **Privacy:** none.

### `commits.byClaude`: Commits made by Claude · derived · MVP
- **Source:** T (a Bash command classified as `git commit` with no error). Confirmed with G when available.
- **Limitations:** commits via aliases, scripts or GUI tools are missed.
- **Privacy:** SHAs are meta.

### `commits.inWindow` / `commits.coAuthored`: Commits in session · exact · MVP
- **Source:** G (`git log` in the session window; `Co-Authored-By:` trailer containing "Claude").
- **Limitations:** needs a repository and a working `git`. Commits by the user in the same window count in `inWindow`; `coAuthored` isolates Claude-attributed ones.
- **Privacy:** messages and authors are not kept.

### `git.lines`: Lines changed in git · exact · MVP (M4)
- **Source:** G (`--numstat` for commits in the window).
- **Limitations:** covers committed work only, from whoever wrote it.
- **Privacy:** none.

## Session lore

### `lore.rabbitHole`: Biggest rabbit hole · derived · MVP
- **Source:** T.
- **Calculation:** the user prompt followed by the most tool calls before the next prompt. Value: `{toolCalls, durationMs, promptIndex}`.
- **Limitations:** "rabbit hole" is framing, and a large, planned task looks the same. The prompt text is not shown.
- **Privacy:** none.

### `lore.longestTurn`: Longest turn · derived · MVP
- **Source:** T `turn_duration`.
- **Calculation:** max `durationMs`.
- **Privacy:** none.

### `lore.peakHour`: Peak hour · derived · MVP
- **Source:** T timestamps, local timezone.
- **Calculation:** the local clock hour with the most prompts plus tool calls. Only shown if the session spans ≥ 2 hours. Mainly meaningful in aggregates.
- **Privacy:** none.

### `lore.errorStreak`: Longest error streak · derived · MVP
- **Source:** T.
- **Calculation:** the longest run of consecutive tool calls with `isError`.
- **Privacy:** none.

### `lore.readEditRatio`: Measure twice, cut once · derived · MVP
- **Source:** T.
- **Calculation:** `Read` calls ÷ Edit/Write calls.
- **Privacy:** none.

### `lore.cacheHitRate`: Cache hit rate · derived · MVP
- **Source:** tokens metrics.
- **Calculation:** `cacheRead ÷ (input + cacheRead + cacheWrite)`.
- **Privacy:** none.

### `lore.nightOwl`: Night owl · derived · future
- **Source:** T timestamps, local timezone.
- **Calculation:** share of activity between 00:00 and 05:00 local time.
- **Privacy:** none.

### `lore.patterns`: Unusual session patterns · heuristic · future
- **Source:** Session metrics (metadata only).
- **Calculation:** a bundled rule list, e.g. one-shot (1 prompt, ≥ 1 edit), marathon (active > 3 h), surgeon (many edits, ≤ 2 files), explorer (reads ≫ edits), all-green (tests run, no errors). Each rule is documented here when added.
- **Privacy:** none.

### `lore.personality`: Session personality · heuristic · future
- **Source:** metadata-only version from Session metrics (default). An opt-in text-informed version comes later.
- **Calculation:** deterministic rules mapping metric thresholds to an archetype. The rules are documented here when added. No LLM calls.
- **Privacy:** none (metadata version); text (opt-in version).

### `lore.recurringPhrases`: Claude's catchphrases · heuristic · future, opt-in
- **Source:** T assistant `text` entries.
- **Calculation:** n-gram frequency, in memory, with stop-phrase filtering.
- **Limitations:** needs response text.
- **Privacy:** text. **Opt-in.** Computed at render time and **never archived**. Never included in exports without an explicit per-export flag.

### `lore.skillsUsed` / `lore.slashCommands`: Skills and commands · exact · future
- **Source:** T (`Skill` tool calls, `system/local_command`).
- **Privacy:** meta (skill and plugin names).

### `lore.subagents`: Subagents spawned · exact · future
- **Source:** T. Subagent files `<sessionId>/subagents/agent-<id>.jsonl`, plus `agentType` and `model` from `.meta.json` (verified in M0 §2).
- **Calculation:** count, by `agentType`. Their tokens are already part of the session's token metrics.
- **Privacy:** none. `meta.json` `description` is free text and is never read.

## Aggregate metrics (future: `--project`, `--week`, `--month`, `wrapped`)

Computed only from archive entries (A), never from raw transcripts, so that they work after cleanup. The provenance of an aggregate is the weakest provenance of its inputs.

| Id | Description | Provenance |
|---|---|---|
| `agg.sessions` | Session count | exact |
| `agg.activeTime` | Sum of active time | heuristic |
| `agg.tokens`, `agg.apiEquivalent` | Sums | as inputs |
| `agg.topProjects`, `agg.topLanguages`, `agg.topTools` | Rankings | derived |
| `agg.busiestDay`, `agg.peakHour`, `agg.streak` | Calendar patterns (local time) | derived |
| `agg.longestSession`, `agg.biggestRabbitHole` | Records | as inputs |
| `agg.coverage` | Which dates have archived data (gaps from before first use are shown, never filled in) | exact |
